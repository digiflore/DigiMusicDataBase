## Description
DigiMusicDataBase est une application musicale développée en PHP. Elle utilise l'API de Spotify. Vous pouvez faire des recherches, consulter les différents artistes, albums et chansons disponibles sur Spotify. Des liens permettent d'écouter directement sur Spotify. Selon vos recherches, mon application vous propose des artistes pour améliorer votre expérience musicale et aller plus loin.

---

## Prérequis
Avant d'installer ce projet, assurez-vous d'avoir les éléments suivants installés sur votre machine :
- [PHP](https://www.php.net/) >= 8.0

---

## Fonctionnalités
- Application sur navigateur
- Faire des recherches musicales
- Consulter des artistes, albums disponibles sur Spotify
- Liens permettant d'écouter votre musique sur Spotify
- L'application propose des suggestions musicales basées sur vos recherches

---

## Installation
1. **Téléchargez le projet** :  
   - Soit en cliquant sur le bouton **Code > Download ZIP** sur GitHub, puis en extrayant le dossier.  
   - Soit en clonant le dépôt avec Git :  
     ```bash
     git clone https://github.com/digiflore/digiMusicDataBase.git
     ```
2. Ouvrez le dossier téléchargé.
3. Double-cliquez sur le fichier `index.php` pour lancer le jeu dans votre navigateur.
4. Démarrer une partie et amusez-vous !

---

## Usage
1. Ouvrez l'application dans votre navigateur.
2. Tapez le nom d'un artiste, d'un album ou d'une chanson dans la barre de recherche.
3. Cliquez sur les vignettes pour consulter les détails et écouter la musique sur Spotify.
