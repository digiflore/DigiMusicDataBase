# DigiMusicDataBase
DigiMusicDataBase est une application musicale utilisant l'API de Spotify. Vous pouvez faire des recherches, consultés les différents artistes, albums et chansons disponibles sur Spotify. Des liens permettent d'écouter directement sur Spotify. Selon vos recherches, l'application vous propose des artistes pour améliorer votre expérience musicale et aller plus loin.

## Prérequis
- Un navigateur Internet
- WampServer (ou tout autre plate-forme de développement Web) pour faire tourner PHP.
